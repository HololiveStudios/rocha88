# Rocha 88 - Catálogo Interativo de Brindes e Presentes Corporativos

## 1. Objetivo e Finalidade
Aplicação web moderna para navegação em catálogo de brindes executivos com busca em tempo real e visualização rica de produtos.

## 2. Tecnologias Utilizadas
- React, TypeScript, Vite, Tailwind CSS, Radix UI, Lucide React, React Router

## 3. Arquitetura e Estrutura de Diretórios
Single Page Application (SPA) modular em React com roteamento via React Router e componentes visuais construídos sobre primitives do Radix UI.

## 4. Principais Arquivos e Responsabilidades
- `src/App.tsx`: Roteamento e estrutura principal da aplicação.
- `src/`: Telas de catálogo, detalhes do produto e contato.
- `package.json`: Definição de dependências do ecossistema React.
- `vite.config.ts`: Configurações de compilação rápida com Vite.

## 5. Funcionalidades Identificadas
- Busca instantânea e filtros por categoria de brindes
- Páginas de detalhe de produto com especificações técnicas e materiais
- Design responsivo adaptável para celulares e computadores

## 6. Como Compilar ou Executar
```bash
npm install
npm run dev
# Build de produção: npm run build
```
